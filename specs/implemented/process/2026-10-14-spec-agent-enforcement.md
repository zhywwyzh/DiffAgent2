# 后续 agent 契约编写强制入口决策

Status: implemented
Date: 2026-10-14
Record-Format: structured

## 背景

使用者要求规范能够持续约束后续 AI 修改。完整规则已在注册表 README，
根 AGENTS 原有说明仍缺少必须完整读取模板和报告实际检查结果的明确入口。

## 决策

根 AGENTS 增加契约编写强制入口；完整执行义务归注册表 README 的 A1–A5。
新增 Cursor alwaysApply 规则引导读取根 AGENTS，不复制详细规范。
修正根 AGENTS 中已经过时的门禁路径示例，指向实际存在的只读入口。

## 理由与放弃的选项

将读取义务放在仓库指令入口，使后续加载仓库指令的 agent 有明确执行路径。
注册表保留唯一规则归属，避免多份模板和门禁要求分叉。
不安装预提交钩子，也不以自动加载规则替代实际执行检查或测试许可。

## 影响

契约任务必须先读完整规则、按类型修改、同步登记与引用，并如实报告检查范围和结果。
文档检查授权不扩展为业务测试、构建、部署或业务内容审查。
这些文件提供仓库执行约束，实际保障仍依赖客户端加载指令、agent 遵守及门禁执行。

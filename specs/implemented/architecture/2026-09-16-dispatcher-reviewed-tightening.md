# dispatcher 经跨版本审核后的收紧与保留决策

Status: implemented

日期：2026-09-16

依据：`l3-core-boundary.spec.md`、`l3-skill-contract.spec.md`、`l3-migration-protocol.spec.md`，以及用户逐项审核后的执行授权。

本轮确认：DiffAgent2 新版缺少当前读取方，不足以证明参数或字段没有用途。DiffAgent2 旧版的 VLA、飞行技能与记录服务仍消费停止记录开关、返航快照/游标、动作上下文、会话标签和思考调试目录。它们暂时保留，后续接入线索集中维护在 `doc/l3-dispatcher-planner/rest/`，由 `AGENTS.md` 提供读取入口；该目录是过程台账，不建立第二份契约权威。

本轮只删除跨版本核对后确认冗余的构造回调、纯文本队列副本和分发重复参数，并按用户明确要求删除首帧缓存残留。结构化队列、任务文本、位置快照写入、PendingAction 及其清理仍保留。无实际作用的状态设置尾部分支删除，停止入口的行为开关改为关键字专用，六态与方法白名单不变。

急停目标维持“急停悬停”。当前 dispatcher 只发急停信号，旧版额外悬停目标尚未接入，因此不以新版暂时裁剪的行为为依据改名或宣称完整悬停能力已完成。下游停止轨迹和额外 hover goal 是否需要并存，由未来执行链接入时验证，避免两个目标互相覆盖。

独立修复了硬停先于推理线程启动时被 INIT 覆盖的问题。该修复有专门回归，不借收紧之名扩展其他停止语义。

本记录冻结结构理由；保留项状态、触发时机和实现验收证据继续在 rest 台账维护。当前生产工具仍为空，通用核心测试通过不代表飞行链路已经恢复。

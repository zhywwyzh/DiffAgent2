# 当前任务强制取消与独立停止确认决策

Status: implemented

日期：2026-10-10

代码已落盘，未编译、未运行验收。权威行为归执行缝、工具面、技能和基础飞行动作契约；
实施记录见[优化方案](../../../doc/l3-dispatcher-planner/iteration/design-task-cancel-emergency-hover.md)。

合法取消使当前任务及派生指令立即失效，释放调用槽与任务归属，并独立尝试全局悬停请求和
对应 Action Cancel。取消不等待普通任务队列或规划完成才关闭运动输出。保持命令及停止
确认由设备记录独立管理；停止超时保留设备故障，不能恢复旧任务。

本次调整替代原生 action 决策中“普通取消不发急停、任务 owner 保留到停稳”的归属。
调用终态与物理停稳分别记账，取消终态只提交一次；新运动在停止确认前被阻止。

命令输出仲裁独立于长规划锁，保留正常控制节律。EGO 与 SUPER 在进程内直接使用原生输出；
DIFF 的独立轨迹跟踪进程以启动标识和输出代次拒绝旧轨迹，并回报保持输出接管。
这是原生执行链的直接修改，不保留旧目标消息或协议转接层。

释放范围只有当前任务的目标、轨迹、指令、多腿状态和 owner；地图、建图更新、定位、
传感器、控制心跳、有效返航原点、注册表与通信端点保留。取消不等同于进程关闭或系统重置。

CoPaw 与仓库外 elastic-tracker 的实现未定位，当前交付不能证明按钮至设备的闭环。
已交付的软件输出保护不能撤回网络或外部控制器已缓存的指令；实际制动时间仍须运行证据。

## 4. 方案决策

### VLA 图示修订方案

- 标签黑底补充修订：新增背景矩形没有 SVG `fill` 属性，依赖新 CSS 的白色填充；页面仍以固定地址引用样式。截图的黑色背景及旧文字描边与新 HTML 配旧 CSS 的表现一致，但未读取浏览器缓存，缓存原因属于推断。先在背景矩形写明白色填充，再用静态资源内容摘要生成 CSS/JS 版本查询参数，避免更新后继续复用旧资源。仅重新生成页面，不运行测试或浏览器验收。

- 问题依据：`flight/service.py:828` 有循环，`:897` 在可见时退出循环，`:954` 等待旋转腿；原图漏掉成功后返回取帧的边。原生成器跨行折线还穿过节点，造成标签叠加。这是网页表达错误，不能据此判定运行代码缺少循环。
- 修改范围：只修订图谱生成器、样式、VLA 内容及生成页面，不修改飞行运行源码。
- 图示拆解：同一目标取帧推理 → 可见性判断；不可见 → 预算判断 → 旋转并等待结果 → 成功返回取帧。预算耗尽、准入拒绝、超时和失败明确终止；可见才进入几何接地及导航执行。
- 排版与导航：增加显式折线路径及标签坐标，让回边绕开节点；标签使用独立背景而非文字描边；限定图形放大尺寸，明确中英文字体回退；关键节点直接链接对应源码行。
- 删除项：替换原错误 VLA 图，不保留为旧版兼容图。
- 执行：先记录本方案，再修改内容及生成器，最后仅重新生成静态页面。按统一声明不运行测试、浏览器视觉验收或其他验证性验收。

- 统一目录：`doc/code-atlas/index.html` 为入口，`atlas.css` 为样式，`atlas.js` 为阅读交互，`content.json` 为解释内容，`generate.py` 为离线生成器，`sources.html` 为带行号的源码摘录。
- 命名：文件采用小写英文语义名；章节采用稳定的短英文锚点；界面及解释正文采用简体中文。
- 接口：普通 HTML 锚点作为导航基础；搜索、章节高亮和图内跳转渐进增强；无 CDN、无运行服务依赖。
- 证据：解释就近引用相对源码路径及实际行号；源码摘录页支持行号定位，并注明脱敏或省略内容。
- 图示：使用内联 SVG 或 HTML 节点连接，确保离线可读、节点可跳转。

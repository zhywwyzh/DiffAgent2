## 1. 背景与动机

当前目录平铺，长标题密集，首页缺少头图。需要让读者先选择任务，再定位系统层次，而不必从长目录逐项查找。

- `doc/code-atlas/generate.py:126`：首页仅有文字介绍与两个链接，没有总览插图及任务入口。
- `doc/code-atlas/atlas.js:18`：搜索只隐藏章节链接，尚未处理目录分组。
- `doc/code-atlas/atlas.css:1`：导航标题直接使用完整章节标题，小字号与密集列表影响扫读。

## 3. 目标与约束

- 目标：六组折叠目录、简短导航标题、任务入口、可点击的系统头图、分组阅读分隔。
- 非目标：复制参考项目运行描述、增加未证实能力、修改运行系统、发布或提交。
- 硬边界：仅修改网页产物；不添加接口转接器；直接替换旧平铺目录与旧文字首页；不运行测试或浏览器验收；纳入版本控制的内容不记录参考项目本地主机路径。

## 4. 方案决策

- 目录保持 `content.json`、`generate.py`、`atlas.css`、`atlas.js`、`index.html`、`sources.html`；新增 `figures/runtime-overview.svg`，集中存放独立矢量图。
- 命名沿用小写短横线文件名与稳定章节锚点。
- 内容增加 `navigation` 分组定义与章节 `nav_title`，统一驱动侧栏、正文顺序、章节分组标题和首页阅读路线。
- 六组：系统导读、按任务阅读、站端与通信、机端执行、部署与运维、接口与源码。
- 头图采用离线 SVG，明确站端、机端、下行请求和上行反馈，链接当前说明章节；不使用远程字体或图片。
- 搜索时展开命中组并隐藏空组；章节跳转时自动展开所在组；源码页按代码路径所属模块分组。
- 保留已有章节及源码锚点身份，目录标题与正文长标题分开。

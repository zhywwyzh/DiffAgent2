# 未接入跟随预留清理方案

> 摘要：依据用户明确要求，移除未接入的目标跟随预留及相关说明，为后续独立能力迁入清理边界。

## 0. 元信息

| 项 | 值 |

| 目标路径 | `l3-dispatcher-planner/` 及对应契约、迁移文档 |
| 状态 | done（代码修改完成，未测试、未验收） |
| 关联文档 | `specs/implemented/inner/l3-execution-seam.spec.md`；`doc/l3-dispatcher-planner/rest/README.md` |

## 1. 背景与动机

用户要求当前仓库清除未接入目标跟随能力的预留及残留说明。此前保留字段的决定被本次明确删除指令覆盖。

## 2. 现状事实（问题清单）

- `l3-dispatcher-planner/ros_packages/utils/quadrotor_msgs/msg/WaypointTarget.msg:4`：存在未接入的跟随目标布尔字段。
- `l3-dispatcher-planner/ros_packages/planner/planner_execution/include/planner_execution/execution_ports.h:14`：领域目标重复保存该字段。
- `l3-dispatcher-planner/ros_packages/planner/planner_execution/src/action_server_ros.cpp:54`：适配层复制该字段。
- 三后端 `execution_backend_ros.cpp` 的目标检查入口：只拒绝该预留字段，没有对应执行能力。
- `l3-dispatcher-planner/ros_packages/dispatcher/dispatcher/support/config.py:85`、`:220`：配置示例及偏航开关注释仍引用未迁入能力。
- `specs/implemented/inner/l3-execution-seam.spec.md:21`、`:94`：契约仍列出预留字段；迁移台账及历史记录也存在保留说明。

## 3. 目标与约束

- 目标：消息、领域结构、适配、后端与文档同步删除预留；清理误导性文字。
- 范围外：通用轨迹执行、偏航控制及第三方库元数据、算法术语；不研究或修改 DiffAgent2 旧版。
- 硬边界：不引入转接器，不保留兼容字段或桩。按用户统一声明不读取测试材料、不执行测试或验证性验收，包括 spec 门禁。

## 4. 方案决策

- 目标目录树：沿用 `dispatcher/support/`、`planner/planner_execution/`、三后端及 `utils/quadrotor_msgs/msg/`；不增加目录或转接模块。

| 类型 | 规范 | 示例 |
|----|----|----|
| 文件与类 | 保持现有领域归属和命名 | `WaypointTarget.msg`、`Target` |
| 字段 | 仅表达当前可执行目标 | `look_forward`、`ground_approach` |
| 注释 | 用偏航控制和前视描述轨迹机制 | 偏航前视方向 |

- 接口形态：删除未接入跟随字段；消息签名有意变化，生产方和消费方须同步重新生成消息并构建。
- 旧接口 → 删除：无兼容读取、桥接或占位字段。
- 历史记录：保留当时曾恢复附加字段的事实，移除旧接口名称并注明被本轮清理取代，避免仍被误读为现行保留要求。

## 5. 迁移映射表

## 6. 删除清单

| 删除项 | 理由 |
|----|----|
| 跟随字段、适配赋值及拒绝分支；无消费者的感知传感器开关 | 当前无执行能力且用户明确要求清除 |
| 相关文档中的旧字段名称及外部接入预留 | 不作为未来能力的实现基础或现行承诺 |
| 上一轮参数方案中的原领域前缀拼写 | 用户要求清除残留；保留新参数配置说明 |

## 7. 实施步骤（P0/P1/... 分期）

### P0 — 方案及契约

- 范围：先落盘方案，再更新执行缝的现行目标定义。
- 行为不变式：不扩大为删除通用偏航或轨迹控制能力。
- 验收：按用户声明跳过。
- 回退：成组恢复契约和方案。

### P1 — 接口和代码

- 范围：消息、领域结构、适配及三个后端同步清理，替换过时注释。
- 行为不变式：已有合法目标的执行策略保持不变；未支持字段直接退出接口。
- 验收：未获许可不运行测试或构建。
- 回退：同步恢复全部消息消费方，禁止只恢复单侧。

### P2 — 文档收敛

- 范围：索引、台账、当前及历史方案同步清理。
- 行为不变式：历史证据不变为当前运行证据。
- 验收：未获许可跳过验证性验收。
- 回退：成组恢复文档与接口。
